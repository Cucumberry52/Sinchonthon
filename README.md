# 신촌ON

**2026 신촌톤 4팀 · 동상 수상**

**신촌의 사람과 기회를 ON하다**

## 프로젝트 주제

**학교의 경계를 넘어 사람을 찾고, 함께할 기회를 발견하는 대학생 네트워킹 플랫폼**

신촌 대학권 학생들은 학교별 커뮤니티에 흩어져 있어 다른 학교 학생을 만나기 어렵습니다. 스터디나 프로젝트 팀원을 찾으려면 여러 채널을 오가야 하고, 함께하고 싶은 사람의 기술과 활동 경험을 확인하기도 쉽지 않습니다.

신촌ON은 이 과정을 한곳에 모았습니다. 학생들은 학교·관심 직무·기술 스택으로 동료를 찾고, 프로필에서 경험과 포트폴리오를 살펴본 뒤 스터디·프로젝트·커피챗 등에 참여할 수 있습니다.

[팀 기획 문서](https://github.com/2026-Sinchonthon/Team4-Backend/blob/main/PROJECTS.md)

## 주요 기능

- 학교 이메일 인증 및 회원가입, 온보딩
- 관심 직무와 기술을 바탕으로 네트워킹 프로필 탐색
- 참가 중인 모임과 추천 콘텐츠를 확인하는 홈 화면
- 모임 모집, 네트워킹 행사, 채용 공고를 모아 보는 피드

## 담당 역할

**백엔드 개발 — 네트워킹 프로필, 홈, 통합 피드**

| 기능 | 구현 내용 |
| --- | --- |
| 네트워킹 프로필 | 사용자 프로필 목록·검색·상세 조회 API를 구현하고, 프로필과 기술 정보의 JPA 엔티티 관계에 맞춰 조회 로직을 정리했습니다. |
| 홈 | JWT로 인증된 사용자를 기준으로 내 프로필, 참가 중인 모임, 추천 프로필·모임 등을 조회하는 API를 구현했습니다. |
| 통합 피드 | 모집·행사·채용 공고를 한 번에 조회하는 페이지네이션 API를 구현했습니다. 커피챗과 네트워킹 모임을 피드에 노출하고, 채용공고 기능 병합 전에는 해당 목록을 비워 반환하도록 처리했습니다. |
| 검증 | Docker로 실행한 MySQL 환경에서 프로필 검색·상세 조회, 인증 사용자 기준 홈 조회, 모임·커피챗 피드 조회를 통합 테스트했습니다. |

## 기술 스택

Java 21 · Spring Boot · Spring Data JPA · Spring Security · JWT · MySQL · Docker Compose
